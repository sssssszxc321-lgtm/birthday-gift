# Подарок на день рождения — инструкция

Это статический сайт для Vercel с тремя API-функциями. Создание подарка сохраняет данные и медиа в Vercel Blob, поэтому фотографии не попадают в URL.

## Что нужно сделать один раз

1. Создай новый репозиторий GitHub, например `birthday-gift`.
2. Загрузи **все файлы и папку `api` из этого архива**, сохранив структуру.
3. На Vercel нажми **Add New → Project** и импортируй этот репозиторий.
4. В проекте Vercel открой **Storage → Create Database → Blob** и создай Blob Store, подключив его к этому проекту.
5. Убедись, что Blob Store подключён именно к проекту и есть переменная окружения для Blob (обычно `BLOB_READ_WRITE_TOKEN`). Если подключал Blob после первого Deploy, открой Deployments и сделай **Redeploy**.
6. Открой `https://ТВОЙ-ДОМЕН.vercel.app/create.html`.

## Проверка

Сначала создай подарок без фото. Затем проверь с одной фотографией. После этого попробуй добавить несколько фото и короткий MP3.

## Важно

- Этот вариант не использует is.gd.
- Фотографии автоматически сжимаются в браузере.
- Чтобы не упираться в лимит тела запроса Vercel, общий размер сжатых фото и музыки ограничен примерно 3 МБ. Для музыки выбирай короткий MP3.
- Если появится ошибка, на экране будет понятное сообщение. Проверь **Vercel → Deployments → Function Logs** для деталей.
- Blob Store должен быть Public, так как получатель открывает фото и аудио по публичным URL.
